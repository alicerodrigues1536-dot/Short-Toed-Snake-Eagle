# Short-toed Snake Eagle: flight behaviour and migration

Analysis of GPS tracking data from Short-toed Snake Eagles (*Circaetus gallicus*) during migration (R, Python, Quarto).

## Contents

- `analyses/`: Quarto notebooks on flight types, migration routes, trajectories, wind drift and age-group comparisons
- `soaring_strategy/`: soaring strategy analysis
- `figures/`: main figures

## Tools

R · Python · Quarto

*Raw GPS data are not included.*
